# Deploying ledger.vaultwares.ca

Tailnet-only site serving the agent-ledger dashboard.

## Architecture

```
agent-ledger repo
  ├── scripts/           PowerShell: generate JSON data from events
  ├── site/              React/Vite/Tailwind v4 app
  │   ├── public/data/   JSON data files (generated by scripts)
  │   └── dist/          Built SPA (served by nginx)
  └── deploy/            nginx config + deploy script
```

## One-time VPS setup (greencloud-vps)

### 1. Clone the repo

```bash
sudo mkdir -p /opt/sites
cd /opt/sites
git clone https://github.com/p-potvin/agent-ledger.git
cd agent-ledger
git submodule update --init --depth 1 vaultwares-themes
```

### 2. Create the web root

```bash
sudo mkdir -p /var/www/ledger.vaultwares.ca
# Important: deployments are executed by `vw-webhookd` which runs as `vwdeploy`.
# The web root must be writable by `vwdeploy`.
sudo chown -R vwdeploy:vwdeploy /var/www/ledger.vaultwares.ca
```

### 3. Tailscale DNS

Add `ledger.vaultwares.ca` to your Tailscale DNS configuration so it resolves to `100.73.93.84` (greencloud-vps Tailnet IP).

### 4. TLS certs

Option A — Tailscale HTTPS certs:
```bash
tailscale cert ledger.vaultwares.ca
sudo cp /var/lib/tailscale/certs/ledger.vaultwares.ca.crt /etc/nginx/certs/
sudo cp /var/lib/tailscale/certs/ledger.vaultwares.ca.key /etc/nginx/certs/
```

Option B — Let's Encrypt (if the domain has a public DNS record):
```bash
sudo certbot --nginx -d ledger.vaultwares.ca
```

### 5. Install nginx vhost

```bash
sudo cp deploy/nginx-ledger.conf /etc/nginx/sites-available/ledger.vaultwares.ca
sudo ln -sf /etc/nginx/sites-available/ledger.vaultwares.ca /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

### 6. Register with vw-webhookd

Add `agent-ledger` to the webhook handler's deploy config so pushes to `main` trigger `deploy/deploy.sh`.

## Manual deploy

```bash
cd /opt/sites/agent-ledger
bash deploy/deploy.sh
```

## Verification

From a tailnet device:
```bash
curl -s -o /dev/null -w "%{http_code}" https://ledger.vaultwares.ca/
# Expected: 200

# From outside the tailnet:
curl -s -o /dev/null -w "%{http_code}" https://ledger.vaultwares.ca/
# Expected: 403 (denied by nginx allow/deny)
```
